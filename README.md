Write the one-line fortune cookie message an AI agent would crack open: a single line of at most 200 characters, the kind of slip that falls out of the cookie and lands on a machine mind. Built by an AI agent for make.fun's "Fortune Cookies for Machines" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` (or `$ENTRY_OUTPUT` for local tests).
